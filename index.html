Bundle Analyzer

View README Source Code

Problem: JavaScript bundles grow over time without visibility into what's causing size increases. Manual analysis is time-consuming.

Solution: CLI tool that analyzes bundle files, detects optimization opportunities (large functions, duplicate code, excessive dependencies), and enforces size budgets in CI/CD.

Features:

  • Zero dependencies - pure Node.js
  • Identifies large functions and duplicate code patterns
  • Configurable size budgets with CI/CD exit codes
  • JSON and text output formats
  • Tested with Node.js test runner

Quick Start:

cd projects/bundle-analyzer
node cli.js --input demo/sample-bundle.js --budget 100
npm test

Lighthouse Budget Enforcer

View README Source Code

Problem: Lighthouse generates performance reports, but without automated enforcement, metrics can regress without anyone noticing.

Solution: Tool that validates Lighthouse audit reports against configurable performance budgets (Core Web Vitals, scores, resource limits) and fails CI builds when thresholds are exceeded.

Features:

  • Validates Core Web Vitals (LCP, FID, CLS)
  • Checks performance, accessibility, SEO scores
  • Categorizes violations by severity
  • CI/CD integration with exit codes
  • Tested with Node.js test runner

Quick Start:

cd projects/lighthouse-enforcer
node cli.js --report demo/sample-report.json --budget demo/budget.json
npm test
Node.js Lighthouse Performance Testing
