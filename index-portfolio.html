Lighthouse Budget Enforcer

Docs Code
Problem → Constraint → Lever → Result Lighthouse audits generate reports, but without enforcement they're just numbers. Constraint: Must integrate with existing CI/CD without external services. Lever: JSON-based budget validation with configurable thresholds. Result: Automated performance gates that fail builds on regression, zero dependencies.

Quick Start

node cli.js --report demo/sample-report.json --budget demo/budget.json

Architecture

Post-audit validator (not a runner). Extracts metrics from Lighthouse JSON reports, compares against configurable budgets (Core Web Vitals, scores, resource limits), categorizes violations by severity, and fails CI builds when thresholds exceeded.

Decision: Validator vs Runner

Trade-off: Separated enforcement from audit execution. Lighthouse CLI already excellent; adding Chrome/Puppeteer would bloat tool 250MB+. Result: 8KB tool that works with any Lighthouse source (CLI, CI service, PageSpeed API).
